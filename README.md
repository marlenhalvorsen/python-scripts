# Python Scripts

A collection of small Python scripts and automation projects I'm building to practice scripting and automation with Python.

## What's in here

- **File organizer** — scripts that automatically sort and organize files in a folder based on type or name

## Goals

- Get comfortable writing Python scripts from scratch
- Automate repetitive tasks
- Learn best practices as I go

## Running a script

Make sure you have Python installed, then run any script with:

```bash
python script_name.py
```

Some scripts may have dependencies. If so, install them with:

```bash
pip install -r requirements.txt
```
